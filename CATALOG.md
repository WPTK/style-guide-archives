# Style Guide Catalog (leads)

Leads for the archive: brand identity manuals, graphic standards, editorial style manuals, technical-writing guides and software UI guidelines, from organisations that still exist and ones that don't. This file lists where each guide lives online. It does not hold the guides themselves.

Compiled 2026-11-19 from ten web-research passes: three broad ones, then seven gap-fills. No PDFs were downloaded or opened; the researchers read landing pages and listings only. The last column is a link check (HEAD request, or a 1-byte ranged GET where HEAD is refused). It shows whether the URL answers, not whether the file is the guide it claims to be.

## Reading the tables

**Link check** (717 unique links: 622 answer, 79 unverified, 16 dead; two rows have only dead links and are kept as leads): `✓` the URL answers (`pdf` and size shown when the server says so); `?` could not be verified from this machine (bot-blocked 403, rate-limited, Project Gutenberg 503, or a TLS or connection failure); `✗` the server says 404 or 410. One mark per link, in the order shown. A `✗` row is kept because the title is still a lead; try the Wayback Machine for it.

**Rights** (a note for sorting, not legal advice):

| Code | Meaning |
|---|---|
| PD-US | US federal government work, or a US publication from before 1931. Safe to mirror. |
| ©owner | Copyrighted; the owner publishes it free. Link, or mirror only if the licence allows. |
| ©scan | Copyrighted; the copy is a third-party scan or upload with no permission shown. Link only. |
| CC / OGL | Open licence stated by the owner. Read the terms (NC and SA restrict reuse). |
| ? | Rights not settled. |

Some US publications of 1931 and later enter the public domain on 1 Jan 2027.

**Where to start:** the PD-US rows are the ones the repo can hold outright: the NASA, NPS, NEA/Federal Design Improvement Program, State Dept, IRS, DOT, MUTCD and EPA material in section 2, and the GPO Style Manuals (1894-2000), CIA and Navy style manuals, Strunk, Fowler, Hart's Rules, Chicago 1906-14 and Detroit News in section 3; the NASA, NIST and DoD documentation standards in section 4; and the DoD, NASA and MITRE human-interface guides and MIL-STD-1472 in section 5.

## 8. Coverage gaps

Ten research passes ran: three broad ones, then seven gap-fills (Internet Archive sweeps, Olympic and expo, Europe and the East Bloc, the rest of the world, US government and editorial, computing and UI, and companies and brands). Still missing or thin:

- **Internet Archive collections.** Searches went through its API, which ignores OR groups and returns manualzilla noise for the `manuals` collection. The `manuals_showcase`, `manuals_various` and `digitaltransportation` collections need a browser pass. Result sets of 1,858 and 2,868 hits were never paged; 214 DTIC hits were not read.
- **Constructed URLs.** Many Internet Archive download links were built from an item identifier plus a file name seen in its metadata. The last column says whether each one answers; it does not say the PDF matches its title. No PDF was opened.
- **Not searched.** Nordic, Polish, Russian, Arabic, Hungarian and Korean-specific terms; pictogram and symbol-sign sets; national road-sign manuals; typography standards; Japanese National Diet Library search (Tokyo 1964, Expo 70); BC Archives (Expo 86), State Library of Queensland (Expo 88), Spanish archives (Expo 92); Europeana (page 2 unread), Delpher, Digitale Sammlungen, the full Deutsche Digitale Bibliothek; Trove, Library and Archives Canada, the Open Library API; the bitsavers vendor folders (hp, ibm, dec, xerox, acorn, be, commodore, palm).
- **Blocked or empty for a fetcher.** library.olympics.com and digital.la84.org (JavaScript-rendered; HTTP 418), designtagebuch.de, Gallica, HathiTrust search (403), hfg-archiv.ulm.de (TLS mismatch), Letterform Online Archive (maintenance), bitsavers.org (403), bbc.co.uk, docs.splunk.com, iris.who.int, rm.coe.int. web.archive.org was blocked in the fetch tool, so Wayback links are unverified.
- **Seen on the Internet Archive, not sized or checked.** Twitter, Discord, LinkedIn and Facebook brand books; Oi 2016; Microsoft 2014, Windows Live and Games for Windows guides; Hard Rock, AmericInn and MLS guides; the Economist Visual Styleguide; the Disney Brand Style Guide; Edmonton Transit corporate identity. Manualzilla scrapes with unclear rights were left out: NETGEAR Editorial Style Guide, NCSL Technical Publications Style Guide, IEEE Computer Society Style Guide, 2009 IEEE Standards Style Manual, SCC User-Interface Style Guide 1.0, BlackBerry Wireless Handheld UI Style Guide.
- **Rights.** Most Internet Archive rows are third-party scans (©scan). Public-domain and CC0 marks set by uploaders are recorded as `?`, because the uploader is not the owner. Two uploader accounts (the Bell System and Olympic sets) are worth rechecking for new items.
- **Conflicting dates, unresolved.** NASA manual (1975 in popular accounts, 1976 on the document), NYCTA (1970 vs 1966 per Archivio Grafica Italiana), Bicentennial manual (1973-75), Bell System Vehicle Graphics Manual (identifier says 1970, item metadata says 1973), Worboys Report (April or July 1963).
