# Style Guide Catalog (leads)

Leads for the archive: brand identity manuals, graphic standards, editorial style manuals, technical-writing guides and software UI guidelines, from organisations that still exist and ones that don't. This file lists where each guide lives online. It does not hold the guides themselves.

Compiled 2026-11-19 from three web-research passes. No PDFs were downloaded or opened; the researchers read landing pages and listings only. The last column is a link check (HEAD request, or a 1-byte ranged GET where HEAD is refused). It shows whether the URL answers, not whether the file is the guide it claims to be.

## Reading the tables

**Link check** (306 unique links: 257 answer, 38 unverified, 11 dead before three dead-only rows were dropped): `✓` the URL answers (`pdf` and size shown when the server says so); `?` could not be verified from this machine (bot-blocked 403, rate-limited, Project Gutenberg 503, or a TLS or connection failure); `✗` the server says 404 or 410. One mark per link, in the order shown. A `✗` row is kept because the title is still a lead; try the Wayback Machine for it.

**Rights** (a note for sorting, not legal advice):

| Code | Meaning |
|---|---|
| PD-US | US federal government work, or a US publication from before 1931. Safe to mirror. |
| ©owner | Copyrighted; the owner publishes it free. Link, or mirror only if the licence allows. |
| ©scan | Copyrighted; the copy is a third-party scan or upload with no permission shown. Link only. |
| CC / OGL | Open licence stated by the owner. Read the terms (NC and SA restrict reuse). |
| ? | Rights not settled. |

Some US publications of 1931 and later enter the public domain on 1 Jan 2027.

**Where to start:** the PD-US rows are the ones the repo can hold outright: the NASA, NPS, NEA/Federal Design Improvement Program, State Dept, IRS, DOT, MUTCD and EPA material in section 2, and the GPO Style Manuals, Strunk, Fowler, Hart's Rules, Chicago 1906-14 and Detroit News in section 3.

## 8. Coverage gaps

All three searches ran out of web-search budget. Not covered, or covered thinly:

- Internet Archive's own catalogue search was never run for most topics; the Manuals Showcase collection needs a browser pass.
- Europe, Japan and most of Asia; Australia, New Zealand, India, Nordic countries, Hong Kong, Singapore; UK COI and Design Council history; military manuals; EU and Red Cross history.
- Cisco, Oracle and Atlassian style guides; Russian orthography rules; DECwindows XUI; DoD TAFIM Volume 8 and MIL-STD-1472; HathiTrust full-view checks for early GPO editions.
- Conflicting dates, unresolved: NASA manual (1975 in popular accounts, 1976 on the document), NYCTA (1970 vs 1966 per Archivio Grafica Italiana), Bicentennial manual (1973-75), Bell System Vehicle Graphics Manual (identifier says 1970, item metadata says 1973), Worboys Report (April or July 1963).
