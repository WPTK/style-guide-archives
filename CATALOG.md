# Style Guide Catalog (leads)

Leads for the archive: brand identity manuals, graphic standards, editorial style manuals, technical-writing guides and software UI guidelines, from organisations that still exist and ones that don't. This file lists where each guide lives online. It does not hold the guides themselves.

Compiled 2026-11-19 from fifteen web-research passes: three broad ones, seven gap-fills, then five sweeps by region and by section. No PDFs were downloaded or opened; the researchers read landing pages and listings only. The last column is a link check (HEAD request, or a 1-byte ranged GET where HEAD is refused). It shows whether the URL answers, not whether the file is the guide it claims to be.

## Reading the tables

**Link check** (1171 unique links: 989 answer, 123 unverified, 59 dead; four rows have only dead links and are kept as leads): `✓` the URL answers (`pdf` and size shown when the server says so); `?` could not be verified from this machine (bot-blocked 403, rate-limited, Project Gutenberg 503, or a TLS or connection failure); `✗` the server says 404 or 410. One mark per link, in the order shown. A `✗` row is kept because the title is still a lead. Where the Wayback Machine had a snapshot of a dead link, it is listed beside it as `Wayback`; the four rows with no snapshot are still worth a search by title.

**Where to start:** the PD-US rows are the ones the repo can hold outright: the NASA, NPS, NEA/Federal Design Improvement Program, State Dept, IRS, DOT, MUTCD and EPA material in section 2, and the GPO Style Manuals (1894-2000), CIA and Navy style manuals, Strunk, Fowler, Hart's Rules, Chicago 1906-14 and Detroit News in section 3; the NASA, NIST and DoD documentation standards in section 4; and the DoD, NASA and MITRE human-interface guides and MIL-STD-1472 in section 5.

## 8. Coverage gaps

Fifteen research passes ran: three broad ones, seven gap-fills (Internet Archive sweeps, Olympic and expo, Europe and the East Bloc, the rest of the world, US government and editorial, computing and UI, and companies and brands), then five sweeps by region and section (Asia, the Middle East, Latin America and Africa; the US; editorial and typography; the UK, Commonwealth and Europe; software UI and documentation). The last five shared a 200-search limit and several stopped early. Still missing or thin:

- **Internet Archive collections.** Searches went through its API, which ignores OR groups and returns manualzilla noise for the `manuals` collection. The `manuals_showcase`, `manuals_various` and `digitaltransportation` collections need a browser pass. Result sets of 1,858 and 2,868 hits were never paged; 214 DTIC hits were not read.
- **Constructed URLs.** Many Internet Archive download links were built from an item identifier plus a file name seen in its metadata. The last column says whether each one answers; it does not say the PDF matches its title. No PDF was opened.
- **Not searched.** Nordic, Polish, Russian, Arabic, Hungarian and Korean-specific terms; pictogram and symbol-sign sets; national road-sign manuals; typography standards; Japanese National Diet Library search (Tokyo 1964, Expo 70); BC Archives (Expo 86), State Library of Queensland (Expo 88), Spanish archives (Expo 92); Europeana (page 2 unread), Delpher, Digitale Sammlungen, the full Deutsche Digitale Bibliothek; Trove, Library and Archives Canada, the Open Library API; the bitsavers vendor folders (hp, ibm, dec, xerox, acorn, be, commodore, palm).
